# Sakura Club

Sakura Club is a small productivity project with **two versions: a desktop widget and a web version**.

The desktop version is built with Electron and designed as a compact, draggable macOS-style widget. The web version recreates the experience in the browser.

## Desktop Widget

The Electron version runs as a standalone desktop application and includes:

* Compact draggable interface
* Pomodoro timer
* Current time and date
* Desktop-style widget experience
* Japanese-inspired interface

## Web Version

The web version brings the Sakura Club experience to the browser, making the project accessible without installing the desktop application.

* Responsive browser interface
* Interactive UI
* Pomodoro timer
* Time and date
* Japanese-inspired design

The project allowed me to explore the difference between building a **browser-based experience** and packaging an interface as a **desktop application with Electron**.
